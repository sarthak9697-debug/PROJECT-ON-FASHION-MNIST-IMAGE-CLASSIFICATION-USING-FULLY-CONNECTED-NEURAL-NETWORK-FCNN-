# PROJECT-ON-FASHION-MNIST-IMAGE-CLASSIFICATION-USING-FULLY-CONNECTED-NEURAL-NETWORK-FCNN-
FASHION MNIST IMAGE CLASSIFICATION USING A FULLY CONNECTED NEURAL NETWORK (FCNN) TO CLASSIFY CLOTHING IMAGES INTO 10 CATEGORIES. THE PROJECT INCLUDES IMAGE NORMALIZATION, ONE-HOT ENCODING, MODEL TRAINING, EVALUATION, AND PREDICTION.
